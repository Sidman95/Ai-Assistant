# Пользовательская инструкция

Как пользоваться личным ассистентом задач: Telegram-бот + веб-кабинет.

## Идея в двух словах

Всё, что держите в голове, — сбрасывайте боту в любом виде: текстом, голосовым,
фотографией записки. ИИ сам поймёт, что это (задача, идея, заметка), выделит суть,
сферу, дедлайн и приоритет. Выгрузили мысль — можете про неё забыть: утром спросите
«план на день», вечером — «итоги дня».

## Сущности

| Тип | Что это | Пример |
|---|---|---|
| ✅ Задача | действие с результатом; приоритет, статус, дедлайн | «сдать отчёт до пятницы» |
| 💡 Идея | мысль на будущее; может дозреть до задачи | «сделать подсветку на кухне» |
| 📝 Заметка | справочная информация, может иметь дату с повтором | «ДР Иры 21 июля» |
| 📁 Проект | контейнер-цель, объединяющий задачи/идеи/заметки | «Ремонт кухни» |
| 🏷 Сфера | тег предметной области (несколько на запись) | работа, дом, ремонт, идеи |

Приоритеты задач: **ASAP** (показывается в плане дня даже без дедлайна) → высокий →
средний → низкий. Статусы задач: активная / завершённая / отменённая / переданная (кому).

## Telegram-бот

### Добавление записей

Просто пишите как удобно — бот сам разберёт:

- «завтра сдать отчёт по фроду и позвонить в ЦОД» → **две** задачи с дедлайном;
- «идея: выучить Go» → идея;
- «ДР мамы 3 марта» → заметка с ежегодным повтором (всплывёт в плане дня 3 марта);
- **голосовое сообщение** → распознается и обработается как текст;
- **фото** записки/доски/чека → текст с фото распознается и превратится в записи.

После создания бот показывает карточку с кнопками:

- **✏️ Изменить** — напишите следующим сообщением, что поправить
  («дедлайн пятница, приоритет высокий»);
- **❌ Отменить** — удалить созданное (удаление мягкое, восстановимо);
- **📎 Сохранить оригинал** (для голоса/фото) — по умолчанию файл **не** хранится,
  сохраняется только распознанный текст; кнопка прикрепляет оригинал к записи;
- **🔗 Связать с…** — если бот заметил похожую запись, предложит связать.

### Запросы и команды

Спрашивайте естественным языком:

- «план на день» / «что у меня сегодня?» — задачи с дедлайном на сегодня
  (по приоритету), ASAP-задачи, и контекст: дни рождения, связанные заметки;
- «итоги дня» / «что я сегодня сделал?» — аналитика: завершено, создано, по сферам;
- «отметь отчёт как готово» / «#3 готово» — смена статуса (если бот не понял,
  какую именно, он покажет кнопками последние активные задачи — просто выберите);
- «#3 частично: первую часть сделал, осталась вторая — перенос на завтра» —
  **отчёт о прогрессе**: бот добавит запись в хронологию задачи, при желании
  перенесёт дедлайн, а задачу оставит активной (не закроет и не заведёт новую);
- «задачу с отчётом передал Пете» — статус «переданная» с указанием кому;
- «что у меня по дому?» / «покажи идеи по ремонту» — выборки;
- «перенеси отчёт на понедельник» — правка записи.

> Ссылаться на запись надёжнее по номеру: `#3` (номер показан на карточке). Если
> написать просто «Задача 3», бот тоже поймёт; а на всякий случай всегда можно
> уточнить выбор кнопками.

Слэш-команды — быстрый и надёжный резерв (работают даже при недоступном ИИ):

| Команда | Действие |
|---|---|
| `/plan` | план на день |
| `/report` | аналитика дня |
| `/find текст` | поиск записей |
| `/done 12` или `/done отчёт` | завершить задачу |
| `/settings` | настройки |
| `/help` | справка |
| `/cancel` | сбросить режим правки |

В списках у записей показывается `#номер` — им удобно ссылаться: `/done 12`,
«перенеси #12 на пятницу».

### Уведомления

По умолчанию бот **молчит** и отвечает только на ваши сообщения. Единственное
плановое уведомление — **утренний отчёт** (план дня): включите в `/settings`
(или в веб-кабинете) и задайте время `/report_time 08:30`. Часовой пояс — `/tz Asia/Barnaul`.

## Веб-кабинет

Адрес: `http://ваш-сервер/` (или ваш домен). Вход по логину/паролю из настройки
сервера. Бот и веб работают с одной базой: всё созданное в Telegram сразу видно
в вебе и наоборот.

### Дашборд

- Плитки: активные задачи, завершено, идеи, сделано сегодня.
- Графики: завершённые задачи за 14 дней; активные задачи по сферам.
- Ближайшие дедлайны (клик — открыть запись).
- **ИИ-инсайты**: кнопка «Обновить» — ИИ анализирует агрегаты и делает выводы
  (динамика, перекосы по сферам, риски дедлайнов).

### Разделы «Задачи / Идеи / Заметки»

Списки с фильтрами (статус, сфера, текстовый поиск) и кнопкой «+ Создать».
Клик по записи открывает **редактор**:

- все поля: суть, описание, статус, приоритет, дедлайн, дата заметки с повтором,
  проект, сферы (клик по тегу — вкл/выкл; поле «+ новая» — своя сфера);
- **Связи** — найдите запись поиском и свяжите; связи двунаправленные;
- **Вложения** — прикрепите изображение или аудио к любой записи;
- **Хронология** — комментарии к записи (журнал выполнения);
- «Удалить» — мягкое удаление (данные не стираются физически).

### Проекты — пространства

Проект — это «папка», собирающая задачи, идеи и заметки одной цели. Вкладка
«Проекты» — обзор карточек с прогрессом. Клик по проекту открывает его
**пространство**:

- в шапке — название и описание (редактируются прямо на месте), статус, дедлайн,
  сферы и прогресс «N из M задач»;
- содержимое — три колонки: Задачи, Идеи, Заметки (на телефоне — друг под другом);
- чекбокс завершает задачу на месте, выполненные сворачиваются в «Завершённые»;
- «+» в колонке создаёт запись сразу в проекте; «🔍» — привязывает существующую;
- крестик на карточке (появляется при наведении) убирает запись из проекта,
  не удаляя её;
- у идеи есть кнопка **«→ в задачу»**: создаётся задача проекта, идея уходит
  в архив и остаётся связанной с задачей;
- внизу — хронология (комментарии) самого проекта.

### Настройки

- **Оформление** — светлая, тёмная или системная тема (быстрый переключатель — кнопка
  с луной/солнцем в верхней панели).
- **Уведомления бота** — утренний отчёт (вкл/выкл, время), часовой пояс.
  Синхронизировано с `/settings` бота.

## Полезно знать

- **Приватность**: все данные лежат в вашей базе на вашем сервере. Во внешний ИИ
  уходит только текст обрабатываемого сообщения и минимальный контекст (список сфер
  и названий проектов). Для полностью локального режима можно переключить LLM на
  Ollama (см. инструкцию по развертыванию).
- **Надёжность**: каждую ночь создаётся резервная копия базы, которую бот и ИИ
  не могут изменить или удалить. Все действия ИИ записываются в аудит-лог,
  удаления обратимы.
- **Если ИИ недоступен** (закончился бюджет, сбой сети) — слэш-команды и веб-кабинет
  продолжают работать полностью.
