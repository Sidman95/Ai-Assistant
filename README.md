# 🧠 Личный ассистент задач

Персональный ИИ-ассистент для управления задачами: **Telegram-бот** + **веб-кабинет**.
Скидывайте задачи, идеи и заметки текстом, голосом или фотографией — ИИ распознает,
структурирует и разложит по полочкам. По запросу — план на день и аналитика.

Реализация по документам: `BT_Personal_Task_Assistant.md` (бизнес-требования) и
`TZ_Personal_Task_Assistant.md` (техническое задание).

## Возможности

- **Ввод в Telegram**: текст, голосовые (SpeechKit STT), фото (Vision OCR); одно сообщение
  может породить несколько записей («сдать отчёт и позвонить в ЦОД» → две задачи).
- **Сущности**: задачи (приоритет, дедлайн, статусы), идеи, заметки (с датами и повторами —
  дни рождения и т.п.), проекты, сферы-теги, связи между записями, комментарии-хронология,
  вложения.
- **Сценарии**: «план на день», «аналитика дня», поиск и выборки, смена статуса фразой
  («отметь отчёт как готово»), правки. Слэш-команды (`/plan`, `/report`, `/done`, `/find`)
  работают детерминированно, даже если ИИ недоступен.
- **Веб-кабинет**: полный CRUD, управление связями и проектами, дашборд с графиками
  и ИИ-инсайтами, настройки. Вход по логину/паролю.
- **Утренний отчёт** по расписанию (по умолчанию выключен — бот молчит, пока не спросят).
- **Изолированный бэкап**: суточные копии БД недоступны для изменения боту/ИИ.
- **Приватность**: всё хранится на вашем VPS в SQLite; аудит-лог и мягкое удаление —
  действия ИИ обратимы.

## ИИ-провайдер

По умолчанию — **Yandex AI Cloud**: YandexGPT (через OpenAI-совместимый API),
SpeechKit (голос), Vision OCR (фото). Оплата в рублях, работает из РФ без VPN.

Провайдер LLM меняется **только настройками** в `.env` (`LLM_BASE_URL`, `LLM_MODEL`,
`LLM_API_KEY`) — совместим любой OpenAI-совместимый endpoint: DeepSeek, локальная
Ollama и др.

## Архитектура

```
Telegram ──▶ bot (aiogram) ──┐
                             ├──▶ SQLite (общая БД) ◀── backup (изолированный, cron)
Браузер ──▶ nginx ──▶ web ───┘
            (SPA)   (FastAPI)
```

- `backend/app/core` — общая бизнес-логика (модели, сценарии, ИИ-абстракции)
- `backend/app/bot` — Telegram-бот + планировщик утреннего отчёта
- `backend/app/web` — REST API + авторизация
- `frontend/` — React SPA (Vite + TypeScript + Tailwind + Recharts)
- `nginx/`, `backup/` — прокси/TLS и изолированное резервное копирование
- Всё разворачивается одной командой: `docker compose up -d`

## Быстрый старт

```bash
git clone <репозиторий> && cd Ai-Assistant
cp .env.example .env
nano .env               # заполнить токены и пароли (см. docs/DEPLOYMENT.md)
docker compose up -d --build
```

Веб-кабинет: `http://<IP-сервера>/` (или ваш домен с HTTPS).
